Variáveis & Atribuição PEP 8 & Idiomas

Desempacotamento de Variáveis (Unpacking)

O Python permite trocar o valor de variáveis diretamente sem precisar de uma variável temporária, além de extrair itens de listas com facilidade.

Não-Pythonico 
# Modo Convencional
temp = a
a = b
b = temp
Modo Pythonico 
# Modo Pythonico
a, b = b, a
Listas e Coleções PEP 8 & Idiomas

List Comprehensions ao invés de Loops Simples

List Comprehensions criam novas listas de forma mais concisa, legível e otimizada internamente em C.

Não-Pythonico 
# Modo Convencional
quadrados = []
for x in range(5):
    quadrados.append(x**2)
Modo Pythonico 
# Modo Pythonico
quadrados = [x**2 for x in range(5)]
Formatação de Texto PEP 8 & Idiomas

Formatação com F-Strings Modernas

Introduzidas no Python 3.6, as f-strings são muito mais legíveis, rápidas e permitem executar código direto entre chaves {}.

Não-Pythonico 
# Modo Antigo / Convencional
msg = "Nome: " + nome + " - Nota: " + str(nota)
Modo Pythonico 
# Modo Pythonico
msg = f"Nome: {nome} - Nota: {nota:.1f}"
Segurança & Dicionários PEP 8 & Idiomas

Acesso Seguro a Dicionários com .get()

O método .get() retorna None ou um valor padrão caso a chave informada não exista no dicionário.

Não-Pythonico 
# Pode causar erro KeyError se a chave não existir!
profissao = usuario["profissao"]
Modo Pythonico 
# Seguro e evita travamentos no programa
profissao = usuario.get("profissao", "N/A")
Loops Idiomáticos PEP 8 & Idiomas

Evite 'range(len(lista))', use 'enumerate()'

O enumerate() fornece diretamente tanto o índice quanto o elemento da iteração em uma sintaxe limpa.

Não-Pythonico 
# Não-Pythonico
for i in range(len(frutas)):
    print(i, frutas[i])
Modo Pythonico 
# Modo Pythonico
for i, fruta in enumerate(frutas):
    print(i, fruta)
Arquivos & Recursos PEP 8 & Idiomas

Gerenciadores de Contexto com Bloco 'with'

O bloco 'with' garante o fechamento correto do arquivo ou conexão mesmo que ocorram exceções durante o código.

Não-Pythonico 
# Arriscado: se ocorrer erro antes do close(), o arquivo fica aberto
f = open("dados.txt")
conteudo = f.read()
f.close()
Modo Pythonico 
# Seguro e automanejado
with open("dados.txt") as f:
    conteudo = f.read()
Condicionais PEP 8 & Idiomas

Verificação de Listas Vazias e Valores Truthy

Em Python, coleções vazias ([]), strings vazias (''), o número 0 e None são avaliados como False em contextos booleanos.

Não-Pythonico 
# Redundante
if len(minha_lista) > 0:
    print("Tem itens")
Modo Pythonico 
# Modo Pythonico (Truthy/Falsy)
if minha_lista:
    print("Tem itens")
Condicionais PEP 8 & Idiomas

Uso do Operador Morsa / Walrus (:=)

Introduzido no Python 3.8, o operador := atribui um valor a uma variável dentro de uma expressão.

Não-Pythonico 
# Duas etapas distintas
dado = input()
if len(dado) > 5:
    print(dado)
Modo Pythonico 
# Atribuição e checagem em uma linha
if (n := len(dado)) > 5:
    print(f"Tamanho {n} válido!")
