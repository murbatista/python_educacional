Guias & Documentação Python

Aprenda a sintaxe dos principais comandos Python com exemplos práticos.

print(...)

Entrada/Saída

Exibe uma mensagem ou valor no console de saída.

print("Olá, Mundo!")
print(f"Resultado: {10 + 20}")

Variáveis & Tipos

Básico

Em Python não é necessário declarar tipo. O tipo é inferido automaticamente.

idade = 25          # int
preco = 19.99       # float
nome = "Ana"        # str
ativo = True        # bool

if / elif / else

Controle de Fluxo

Executa blocos de código com base em condições lógicas. Atenção à indentação!

nota = 8
if nota >= 7:
    print("Aprovado")
else:
    print("Reprovado")

for i in range(...)

Repetição

Itera sobre uma sequência de números ou elementos de uma lista.

for i in range(5):
    print(f"Número: {i}")

Listas [ ]

Estruturas de Dados

Coleção ordenada e alterável de elementos.

frutas = ["maçã", "banana"]
frutas.append("laranja")
print(frutas[0]) # maçã

def funcao(...)

Modularização

Define um bloco de código reutilizável que pode aceitar parâmetros e retornar valores.

def somar(a, b):
    return a + b

resultado = somar(5, 10)
